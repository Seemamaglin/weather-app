# Angular Weather Application

## 📌 Project Description
This is a simple Angular standalone application that displays weather forecast data by consuming a public REST API.  
The application fetches weather information on page load, displays it in a responsive table, highlights high temperatures, and supports manual data refresh.  
It is automatically built and deployed to GitHub Pages using GitHub Actions CI/CD.

---

## 🅰️ Angular Version
- Angular 17+
- Standalone Components Architecture
- TypeScript (Strict Mode)

---

## ⚙️ Installation Steps

### Prerequisites
- Node.js 18+
- Angular CLI

### Steps
```bash
# Clone the repository
git clone https://github.com/<https://github.com/Seemamaglin/weather-app.git>/weather-app.git

# Navigate to project directory
cd weather-app

# Install dependencies
npm install

# Run application locally
ng serve
